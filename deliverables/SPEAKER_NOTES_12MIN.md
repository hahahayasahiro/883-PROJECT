My module uses course records to suggest eligible next courses and explain support reminders. It also flags a mark below fifty or attendance below seventy-five percent. In this profile, Mathematics for Computing triggers a reminder, while the passed programming course opens several next-course choices. Each result includes the rule behind it. ## Slide 5 — Learning Progress, Problems and Next Steps — Dequn Shang — 70 seconds

The backend and page are connected, and the suggestions come from stored student records rather than fixed display text. Existing tests confirm that low performance produces a reminder and that unmet prerequisites exclude an advanced course. The main limitation is that eligibility is not the same as a personalised learning path. We currently do not rank by interests, balance a semester workload or use collaborative filtering. The data is small and synthetic, so it cannot support a credible trained risk model yet. My next work is to add more varied course profiles, check boundary cases and improve the explanation of retaking a failed course. After that, we can evaluate a recommendation method against these transparent rules. For the progress report, the acceptance condition is understandable, reproducible suggestions for each demonstration student, with the rule-based status visible rather than described as machine learning.

## Slide 6 — Spaces, Bookings and Fault Reports — Jun Yang — 50 seconds

My facilities module supports room reservations, cancellation and equipment fault reports. Students choose a room and a future time slot of at most two hours. The server checks for overlapping active bookings before saving. In the screenshot, a second attempt at the same slot produces a conflict message. The overlap check and insertion share a database transaction, so simultaneous requests cannot both reserve the slot. Students can cancel only their own reservations. Fault reports create maintenance tickets that Lexi's module reads directly. The current implementation uses a common maintenance queue, without AI fault classification or occupancy prediction.
